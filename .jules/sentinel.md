## 2024-05-18 - Missing Content Security Policy (CSP)
**Vulnerability:** The application was missing a Content Security Policy (CSP), which left it vulnerable to Cross-Site Scripting (XSS) attacks by allowing potentially malicious inline scripts or unintended external resources to be loaded and executed.
**Learning:** The application uses React and Babel standalone via CDN (`cdnjs.cloudflare.com`), which requires `unsafe-inline` and `unsafe-eval` for client-side transpilation. In addition, images and videos from external providers (`image.pollinations.ai`, `pixabay.com`, `www.pexels.com`, `www.videvo.net`) must be whitelisted in `img-src`, `media-src`, and `connect-src`. Missing explicit `media-src` can fall back to an overly restrictive `default-src`, breaking core functionalities.
**Prevention:** Always implement a restrictive CSP meta tag. Explicitly define and whitelist known trusted CDNs and external resource domains, use `unsafe-inline` and `unsafe-eval` only when strictly required by libraries like Babel standalone, and ensure fonts and styles from Google are specifically permitted.
