## 2024-07-03 - Missing Content Security Policy (CSP)
**Vulnerability:** The application was missing a Content Security Policy (CSP). The `<head>` tag did not contain a `<meta http-equiv="Content-Security-Policy">` directive, nor were CSP headers served by the server, allowing the browser to load resources from any origin.
**Learning:** Without a CSP, the application is highly vulnerable to Cross-Site Scripting (XSS) and data injection attacks. Any script or image could be loaded or executed, bypassing the intended security controls. Since the application heavily relies on external resources (React via cdnjs, fonts via Google, images via external APIs), an explicit CSP is required to restrict allowable origins and protect users.
**Prevention:** Always implement a strict Content Security Policy (CSP) using `<meta http-equiv="Content-Security-Policy">` or HTTP headers. Define explicit whitelists for `script-src`, `style-src`, `font-src`, `img-src`, `media-src`, and `connect-src` directives to enforce secure loading of resources. Ensure only necessary and trusted domains are permitted.
