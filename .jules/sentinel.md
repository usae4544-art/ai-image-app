## 2024-05-18 - Missing Content Security Policy (CSP)
**Vulnerability:** The application lacks a Content Security Policy (CSP) header or meta tag.
**Learning:** This is a standalone React application loaded directly into the browser and using Babel standalone to transpile on the fly. To make this secure but functional, `script-src` must include `'unsafe-inline'` and `'unsafe-eval'` (for Babel), along with `https://cdnjs.cloudflare.com`. For dynamic images and video, domains like `https://image.pollinations.ai`, `https://pixabay.com`, `https://www.pexels.com`, and `https://www.videvo.net` must be whitelisted in `img-src`, `media-src`, and `connect-src`.
**Prevention:** Always implement a baseline CSP in web applications. For complex client-side rendered apps using CDNs, carefully identify and whitelist all required domains and execution contexts (like `unsafe-eval` when unavoidable for things like in-browser transpilers) to mitigate Cross-Site Scripting (XSS) risks without breaking functionality.
