## 2024-05-24 - Missing Security Headers (CSP) & Reverse Tabnabbing
**Vulnerability:** The application lacked a Content Security Policy (CSP), allowing any external resource to be loaded and executed, increasing the risk of XSS attacks. In addition, external links opened via `window.open(url, "_blank")` did not specify `noopener,noreferrer`, leaving the app vulnerable to reverse tabnabbing.
**Learning:** For standalone React applications utilizing Babel in-browser, the CSP must include `'unsafe-inline'` and `'unsafe-eval'` for scripts to function properly. Furthermore, explicit directives such as `img-src` and `media-src` must be configured for all third-party media sources (e.g., image.pollinations.ai, pixabay.com, pexels.com, videvo.net) to avoid falling back to a restrictive `default-src`.
**Prevention:** Always include a robust CSP meta tag or HTTP header in web applications, carefully balancing security with operational requirements. Always use `"noopener,noreferrer"` as the third argument in `window.open` or add `rel="noopener noreferrer"` to `<a>` tags when opening untrusted or external URLs in new tabs.
